Fairness in the official build 发牌规则，说在前面

Fair dealing in the current product version 每一手牌
都遵循同一套规则

The shuffle happens before private cards are assigned. The official build does not choose cards by player name, identity, or a favoured seat setting. 系统会先完成洗牌，再分配私牌。官方版本不会按玩家姓名、身份或偏好座位指定牌面。

Shuffle洗牌

Fresh randomness for every hand 每手都重新洗牌

The browser’s secure random-number generator reorders the standard deck before the deal begins. 发牌开始前，浏览器会用安全随机数重新打乱整副牌。

Deck牌组

One complete set of cards 完整的标准牌组

A hand is rejected unless the shuffled result contains exactly 52 unique standard cards. 只有洗牌结果恰好包含 52 张不重复的标准扑克牌，牌局才会继续。

Deal发牌

The same path for every seat 所有座位按同一顺序发牌

The dealer gives one card to each active seat in table order, then repeats that pass for the second card. Board cards continue from the same deck without reusing a card. 系统会按桌面顺序先给每个有效座位发一张，再逐位发第二张；公共牌也从同一副牌中继续发出，不会重复使用。

The boundary is part of the promise 信任边界同样重要

Fair dealing still needs a Trusted Host 规则一致
仍需信任主控设备

In the unmodified official build, every active seat follows the same shuffle and dealing rules. There is no product control for choosing a player’s cards. 在未修改的官方版本中，每个有效座位都遵循同一套洗牌和发牌规则；产品没有为某位玩家指定手牌的控制项。

The current product version still trusts the active host, who holds the deck and can inspect or alter local code. This is not a host-blind or independently verifiable shuffle. Play only with people you trust. 当前版本仍将牌组交给主控设备。它能够查看当前牌组，也可以修改本地代码；因此这不是不必信任主控、也不是可以独立验证的洗牌方案。请只和你信任的人一起使用。

02 · Prepared local table 02 · 无网出行

Airplane Mode 飞行模式

Download one standalone file to every participating device before travel. During play, pair devices over a private, non-isolating Wi-Fi network with two-way QR. 出行前，将同一个独立文件存到每台参与设备。游戏时，使用一个可让设备互相连接的私有 Wi-Fi 网络，再用双向二维码完成配对。

An honest trust model 信任边界，说在前面

Privacy is built into the projection 公共信息放桌上
私牌留在手机里

Hidden cards are filtered before they leave the Trusted Host. Public displays, other seats, diagnostics, and connection services do not receive unrevealed card plaintext. 私牌在离开主控设备前就会被过滤。公共屏幕、其他座位、诊断工具和连接服务都不会收到未亮出私牌的明文。

Trusted Host means trusted. 主控设备必须由你信任的人掌管

The current product version deliberately trusts the active host. The host owns the shuffle, deal, and hand history and can inspect the active deck by design. 当前版本有意将洗牌、发牌和牌局记录集中在这台主控设备上。它按设计可以查看当前牌组。

Before the first hand 开局之前

A few direct answers 几个常见问题
直接回答

Does it use real money? 用真钱吗？

No. The current product is for in-person poker using physical play chips. 不用。这是一款供面对面玩实体娱乐筹码扑克的产品。

Do players need accounts? 需要注册账号吗？

No. Players join the current table using a time-limited invitation. 不需要。玩家通过限时邀请加入这桌牌。

Can a public screen see private cards? 公共屏幕会显示私牌吗？

No. Public projections receive only public table state. 不会。公共屏幕只会收到公开的牌桌信息。

Can the host see the active deck? 主控设备能看到当前牌组吗？

Yes. The current product version names and trusts one active host as the game authority. 能。当前版本由一台主控设备负责主持牌局，并默认信任这台设备。

Can I run it myself? 我可以自行运行吗？

Yes. The project provides a static hosted build and a standalone Airplane HTML file. 可以。项目提供静态网页版和可单独保存的飞行模式 HTML 文件。

Can I play without internet? 没有互联网也能玩吗？

Yes, after every device has the same downloaded Airplane HTML file. Devices still need a compatible, non-isolating private Wi-Fi network and two-way QR pairing. 可以。前提是每台设备都提前保存了同一份飞行模式 HTML 文件；设备之间仍需连接可互通的私有 Wi-Fi，并完成双向二维码配对。
